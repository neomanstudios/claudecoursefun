ระบบอัตโนมัติ & ผู้ช่วย

automation ด้วย no-code

รู้ใน 30 วิ

ต่อ AI เข้ากับ Zapier หรือ Make เพื่อให้งานซ้ำ ๆ ทำเองอัตโนมัติ หลักคิดง่าย ๆ คือ Trigger ที่จุดเริ่ม, ขั้น AI คิดให้, แล้ว Action ลงมือทำผลลัพธ์

Trigger = จุดเริ่มAI step = คิดให้Action = ลงมือทำ

Automation 3 ขั้น

ทุก flow ใน Zapier/Make มีโครงเดียวกันนี้เสมอ

1

Trigger คือจุดเริ่ม

เหตุการณ์ที่จุดชนวนให้ flow ทำงาน เช่น มีอีเมลใหม่เข้า หรือมีฟอร์มถูกกรอก

2

AI step คือสมอง

ส่งข้อความเข้า AI ให้สรุป จัดหมวด หรือร่างคำตอบ แล้วได้ผลลัพธ์เป็นข้อความกลับมา

3

Action คือมือ

เอาผลจาก AI ไปทำต่อจริง เช่น บันทึกลง Google Sheet ส่ง Slack หรือตอบอีเมล

AI เป็นแค่ ขั้นกลาง ใน flow ไม่ใช่ทั้งหมด ความคุ้มอยู่ที่ Trigger และ Action ต่อกับเครื่องมือที่คุณใช้จริงได้แค่ไหน

ลองเลย จับมือทำ
  1. 1
    เข้า zapier.com กด Create → Zaps แล้วเลือก Trigger เป็น Gmail → New Email Matching Search
  2. 2
    เพิ่มขั้นถัดมาเป็น AI by Zapier → Analyze and Return Data (Make เรียก OpenAI/Anthropic module)
  3. 3
    วาง prompt นี้ในช่อง Instructions ของขั้น AI แล้วชี้ตัวแปรเนื้ออีเมลเข้าไป
    อ่านอีเมลนี้แล้วจัดหมวดเป็นหนึ่งใน: สอบถามสินค้า, ร้องเรียน, ใบเสนอราคา, อื่น ๆ ตอบกลับเป็น JSON เท่านั้น: {"category": "...", "summary": "สรุป 1 ประโยค", "urgent": true/false} อีเมล: [เนื้ออีเมล]
  4. 4
    ต่อ Action เป็น Google Sheets → Create Row แล้วแมป category กับ summary ลงคอลัมน์
  5. 5
    กด Test ส่งอีเมลทดสอบเข้ามา ดูว่าแถวขึ้นใน Sheet ถูกไหม แล้วค่อย Publish
ขั้นที่ 1 / 5
ลองใช้ Prompt นี้ (ขั้น AI)
คุณคือผู้ช่วยจัดการ [ประเภทงาน เช่น คำขอจากลูกค้า] อ่านข้อความด้านล่าง แล้วตอบกลับเป็น JSON เท่านั้น ห้ามมีข้อความอื่น: { "category": "[หมวดที่เป็นไปได้ คั่นด้วย /]", "reply_draft": "ร่างคำตอบสุภาพ กระชับ", "needs_human": true/false } ข้อความ: [ดึงตัวแปรจาก Trigger มาวางตรงนี้]
สรุปเวิร์กช็อป
  • ทุก automation คือ Trigger เข้า, AI step คิด, Action ลงมือทำผลลัพธ์
  • บังคับให้ AI ตอบเป็น JSON เพื่อให้ขั้น Action เอาไปแมปต่อได้ง่าย
  • Test ด้วยข้อมูลจริงก่อน Publish เสมอ ไม่งั้น flow ทำงานผิดเงียบ ๆ
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.ใน flow ของ Zapier/Make ขั้น AI ทำหน้าที่อะไร?
เฉลย: AI step อยู่ตรงกลางระหว่าง Trigger กับ Action ทำหน้าที่ประมวลผลข้อความให้
ข้อ 2.ทำไมจึงควรสั่งให้ขั้น AI ตอบกลับเป็น JSON?
เฉลย: JSON แยกเป็นช่อง ทำให้ Action แมปแต่ละค่าไปลงปลายทางได้ตรงจุด
