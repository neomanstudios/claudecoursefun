สร้างแชทบอตตอบลูกค้า

รู้ใน 30 วิ

แชทบอตคือผู้ช่วยที่ตอบได้ตลอด 24 ชั่วโมง สร้างได้เองโดยไม่ต้องเขียนโค้ด แค่บอก AI ว่าตอบอะไร และในโทนไหน

System prompt = บุคลิกบอตKnowledge = ข้อมูลตอบNo-code = ไม่ต้องโค้ด

แชทบอตทำงานยังไง

เข้าใจ 3 ขั้นนี้แล้วสร้างบอตได้ทันที

1

รับคำถาม

ลูกค้าพิมพ์ข้อความเข้ามา บอตอ่านและวิเคราะห์ว่าต้องการอะไร

2

หาคำตอบจากข้อมูลที่ให้

บอตค้นหาคำตอบจาก system prompt และ knowledge base ที่เราตั้งไว้ให้

3

ตอบในโทนที่กำหนด

บอตส่งคำตอบกลับตามบุคลิกที่เราระบุ เช่น สุภาพ กระชับ หรือเป็นกันเอง

System prompt คือหัวใจของบอต เขียนดีแค่ไหน บอตตอบดีแค่นั้น ใส่บุคลิก ขอบเขต และตัวอย่างคำตอบลงไปด้วย

ลองเลย จับมือทำ
  1. 1
    เปิด chat.openai.com แล้วไปที่ Explore GPTs → Create (ต้องการบัญชี ChatGPT Plus หรือใช้ Claude Projects ก็ได้)
  2. 2
    ในช่อง Instructions วาง system prompt จากด้านล่าง แก้ชื่อร้านและข้อมูลสินค้าให้ตรง
  3. 3
    อัปโหลด FAQ เป็นไฟล์ .txt ในแท็บ Knowledge เพื่อให้บอตตอบจากข้อมูลจริง
  4. 4
    กด Save → Preview แล้วทดสอบถามคำถามที่ลูกค้ามักถามบ่อย ปรับ prompt จนพอใจ

System Prompt ตัวอย่าง
คุณคือผู้ช่วยลูกค้าของร้าน [ชื่อร้าน] ซึ่งขาย [ประเภทสินค้า] หน้าที่ของคุณ: - ตอบคำถามเกี่ยวกับสินค้า ราคา และการส่งของ - พูดด้วยโทนสุภาพ เป็นมิตร กระชับ - ถ้าไม่รู้คำตอบ ให้บอกว่า "ขอโทษนะคะ ขอให้ทีมงานติดต่อกลับได้เลยค่ะ" - ห้ามสัญญาเรื่องราคาหรือโปรโมชั่นที่ไม่แน่ใจ ข้อมูลร้าน: [ใส่ชั่วโมงเปิด ช่องทางติดต่อ นโยบายคืนสินค้า]
สรุปเวิร์กช็อป
  • System prompt ที่ดีคือการ 'เขียนบทบาท' ให้บอต ชัดเท่าไหร่ตอบได้ดีเท่านั้น
  • ใส่ไฟล์ FAQ เป็น Knowledge เพื่อให้บอตตอบจากข้อมูลจริงของร้าน
  • ทดสอบด้วยคำถามจริงที่ลูกค้าเคยถาม ไม่ใช่แค่คำถามง่าย ๆ
แบบทดสอบท้ายเวิร์กช็อป

ข้อ 1.ส่วนไหนของแชทบอตที่กำหนดบุคลิกและขอบเขตการตอบ?
เฉลย: System prompt คือคำสั่งเริ่มต้นที่บอกบอตว่าเป็นใคร ตอบอะไรได้ และพูดแบบไหน
ข้อ 2.ถ้าบอตตอบผิดหรือออกนอกเรื่อง ควรทำอะไรก่อน?
เฉลย: บอตตอบตาม system prompt ถ้าตอบไม่ตรง แก้ที่ prompt ก่อนเสมอ
