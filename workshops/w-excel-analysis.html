วิเคราะห์ข้อมูล Excel ด้วย AI

รู้ใน 30 วิ

มีไฟล์ตารางยาว ๆ แล้วงง ให้ Claude Code เขียนสคริปต์อ่าน CSV สรุปยอด และทำกราฟให้เองในเครื่อง ถ้าแค่ถามเร็ว ๆ จะอัปโหลดไฟล์เข้าแชตก็ได้

Claude Code เขียนสคริปต์CSV วิเคราะห์อัตโนมัติสรุป + กราฟ ในคำสั่งเดียว

ดู Claude Code วิเคราะห์ข้อมูล

ชี้ไฟล์ให้ แล้วมันเขียนโค้ดรันวิเคราะห์เองทีละขั้น

ดู Claude Code ทำงาน
คุณอ่านไฟล์ sales.csv แล้วสรุปยอดขายรายเดือน หาสินค้าขายดี 5 อันดับ และทำกราฟให้หน่อย
  • ›อ่านไฟล์ sales.csv ดูว่ามีคอลัมน์อะไรบ้าง
  • ›เขียนสคริปต์ Python (pandas) รวมยอดขายตามเดือน
  • ›จัดอันดับสินค้าขายดี และคำนวณยอดรวม
  • ›สร้างกราฟแท่งเซฟเป็น chart.png
  • ✓เสร็จ สรุปยอดรายเดือน + กราฟ + ไฟล์สคริปต์ที่รันซ้ำได้

ข้อดีของ Claude Code คือมัน เขียนสคริปต์ที่รันซ้ำได้ เดือนหน้าได้ข้อมูลใหม่ ก็รันคำสั่งเดิมได้เลย ไม่ต้องนั่งทำมือใหม่ทุกครั้ง
