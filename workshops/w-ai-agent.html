สร้าง AI agent หลายขั้น

รู้ใน 30 วิ

AI agent คือ AI ที่ทำงาน หลายขั้นต่อเนื่องเอง ตามลูป วางแผน, ลงมือ, ตรวจผล แล้ววนแก้จนเสร็จ Claude Code คือ agent ตัวจริงที่อ่านไฟล์ รันคำสั่ง และแก้ของตัวเองได้

Plan = วางแผนAct = ลงมือVerify = ตรวจแล้ววนแก้

ดู agent ทำงานหลายขั้น

คำขอเดียว แต่ Claude Code วางแผนและลงมือเองหลายขั้นจนจบ

ดู Claude Code ทำงาน
คุณเพิ่มฟีเจอร์ค้นหาในหน้ารายการสินค้า แล้วทดสอบให้ผ่าน
  • ›วางแผน อ่าน products.js ดูโครงข้อมูลและจุดที่ต้องแก้
  • ›ลงมือ เพิ่มช่องค้นหาและฟังก์ชันกรองรายการ
  • ›ตรวจผล รัน npm test ดูว่าเทสผ่านไหม
  • ›วนแก้ เจอเทสตก ปรับโค้ดแล้วรันใหม่อีกรอบ
  • ✓เสร็จ เทสผ่านครบ ช่องค้นหาใช้ได้จริง

ลูปของ agent

ต่างจากแชตตรงที่มันวนทำเองจนงานเสร็จ

1

Plan วางแผน

ย่อยงานใหญ่เป็นขั้นย่อย และตัดสินใจว่าจะเริ่มตรงไหนก่อน

2

Act ลงมือ

ทำขั้นนั้นจริง เช่น แก้ไฟล์ รันคำสั่ง หรือเรียกเครื่องมือ

3

Verify ตรวจแล้ววน

เช็กผลว่าถูกไหม ถ้ายังไม่ผ่านก็กลับไปแก้แล้ววนใหม่จนเสร็จ

หัวใจของ agent คือ ลูป verify มันไม่ได้ทำครั้งเดียวจบ แต่ตรวจผลตัวเองแล้ววนแก้ ยิ่งบอกวิธีตรวจชัด เช่น ให้รันเทส มันยิ่งทำงานแม่น

ลองเลย จับมือทำ
  1. 1
    เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ claude เพื่อเข้าโหมด agent
  2. 2
    ก๊อป prompt นี้ไปวาง ใส่ทั้งงานและวิธีตรวจผลให้ครบ แล้วกด Enter
    ช่วยเพิ่ม [ฟีเจอร์ เช่น ปุ่มกรองตามหมวด] ในไฟล์ [ชื่อไฟล์] ทำตามขั้น: วางแผนก่อน, ลงมือแก้, แล้วรัน [คำสั่งทดสอบ เช่น npm test] เพื่อตรวจ ถ้าทดสอบไม่ผ่าน ให้แก้แล้ววนใหม่จนผ่าน แล้วสรุปสิ่งที่ทำให้ฟัง
  3. 3
    ดูมันวางแผนเป็นขั้น ๆ ก่อนลงมือ คุณกด Enter ยืนยันหรือพิมพ์แทรกเพื่อปรับทิศได้
  4. 4
    พอมันรันเทสแล้วเจอ error ดูว่ามันอ่าน error เองแล้ววนกลับไปแก้ ไม่ต้องสั่งซ้ำ
ขั้นที่ 1 / 4
ลองใช้ Prompt นี้ (สั่งงานแบบ agent)
งานที่อยากได้: [อธิบายงานที่ต้องทำหลายขั้น] ทำเป็นลูปแบบนี้: 1. วางแผน บอกขั้นที่จะทำก่อนลงมือ 2. ลงมือทำทีละขั้น 3. ตรวจผลด้วย [วิธีตรวจ เช่น รันคำสั่ง / เปิดดูผล] 4. ถ้ายังไม่ถูก กลับไปแก้แล้ววนใหม่จนเสร็จ จบแล้วสรุปสั้น ๆ ว่าแก้อะไรไปบ้าง
สรุปเวิร์กช็อป
  • Agent ต่างจากแชตตรงที่วนลูป วางแผน ลงมือ ตรวจผล จนงานเสร็จเอง
  • Claude Code คือ agent ที่อ่านไฟล์ รันคำสั่ง และแก้ของตัวเองได้จริง
  • บอกวิธีตรวจผลให้ชัด เช่น ให้รันเทส แล้ว agent จะวนแก้จนผ่านเอง
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.อะไรคือสิ่งที่ทำให้ AI agent ต่างจากการแชตถามตอบทั่วไป?
เฉลย: Agent ทำงานเป็นลูปต่อเนื่องและตรวจผลตัวเอง ไม่ใช่ตอบครั้งเดียวจบ
ข้อ 2.ทำไมการบอกวิธีตรวจผล เช่น ให้รันเทส ถึงช่วยให้ agent ทำงานแม่นขึ้น?
เฉลย: ขั้น verify ที่ชัดทำให้ agent รู้ว่าผลถูกหรือยัง แล้ววนแก้ในลูปได้เอง
