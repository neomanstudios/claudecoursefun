Agentic Mode คืออะไร ทำงานยังไง

Claude Code ไม่ได้แค่ตอบคำถาม แต่ลงมือทำงานเป็นขั้นตอนเองได้ มาดูทีละขั้นกัน

🎯 จบบทนี้คุณจะ…

  • อธิบาย agentic mode ได้
  • เข้าใจลูป อ่าน→แก้→ทดสอบ
1

agent ต่างจาก autocomplete

autocomplete แค่เติมโค้ด แต่ agent ลงมือทำงานหลายขั้นเอง จากเป้าหมายที่คุณบอก

2

ลูปการทำงาน

Claude จะ วางแผน → อ่านไฟล์ → แก้โค้ด → รันเทส → ตรวจผล แล้ววนซ้ำจนงานเสร็จ

3

ลองดูตัวอย่าง

สั่ง "แก้บั๊กหน้า login" → Claude หาไฟล์ แก้ รันเทส จนผ่านเอง

🧠 เช็คความเข้าใจ

agentic mode ต่างจาก autocomplete อย่างไร?
