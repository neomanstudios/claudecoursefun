Agentic Mode คืออะไร ทำงานยังไง

Claude Code ไม่ได้แค่ตอบคำถาม แต่ลงมือทำงานเป็นขั้นตอนเองได้ บทนี้อธิบายว่า "agent" ทำงานเป็นลูปอย่างไร

🎯 เมื่อเรียนจบบทนี้ คุณจะ…

  • อธิบายความหมายของ agentic mode ได้
  • เข้าใจลูป อ่าน→แก้→ทดสอบ
  • รู้ว่าเมื่อไรควรปล่อยให้ Claude ทำเอง

ลูปการทำงานของ Agent

เมื่อคุณสั่งงานหนึ่งเป้าหมาย Claude จะ วางแผน อ่านไฟล์ แก้โค้ด รันคำสั่ง และตรวจผล วนซ้ำจนกว่างานจะเสร็จ โดยคุณไม่ต้องสั่งทีละขั้น

นี่คือความต่างสำคัญจาก autocomplete ทั่วไป — agent ตัดสินใจขั้นถัดไปเองจากผลลัพธ์ที่เห็น

ตัวอย่างใช้งานจริง

สั่งว่า "แก้บั๊กหน้า login" → Claude หาไฟล์ที่เกี่ยว แก้ รันเทส ถ้าพังก็แก้ต่อจนผ่าน
