ตอนที่ 1

🔌 ติดตั้ง MCP Server

เพิ่มเครื่องมือภายนอกเข้า Claude ด้วยคำสั่ง claude mcp add

1รูปแบบคำสั่งพื้นฐาน

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วใช้รูปแบบนี้:

Terminal
# รูปแบบ: claude mcp add [ชื่อ] -- [คำสั่งรัน server] claude mcp add ชื่อ -- npx -y ชื่อแพ็กเกจ
2ตัวอย่างที่ใช้บ่อย — คัดลอกได้เลย

Context7 (ดึง docs library ล่าสุดเข้า context):

Terminal
claude mcp add context7 -- npx -y @upstash/context7-mcp

GitHub (ให้ Claude สร้าง PR, อ่าน issue):

Terminal
claude mcp add github -- npx -y @modelcontextprotocol/server-github # ตั้ง token ก่อน: export GITHUB_TOKEN=ghp_xxxx

Filesystem (ให้ Claude อ่าน/เขียนไฟล์ในโฟลเดอร์ที่กำหนด):

Terminal
claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem ~/projects

Postgres (ให้ Claude query database):

Terminal
claude mcp add postgres -- npx -y @modelcontextprotocol/server-postgres postgresql://...
3ตรวจสอบ + จัดการ MCP
Terminal
# ดู MCP ที่ติดตั้งทั้งหมด claude mcp list # ดูรายละเอียดตัวใดตัวหนึ่ง claude mcp get context7 # ลบออก claude mcp remove context7
💡
อยากให้ทีมใช้ MCP เดียวกัน? เพิ่ม --scope project จะสร้างไฟล์ .mcp.json ที่ commit ขึ้น git ได้
🆘
ติดตรงไหน พิมพ์ถาม Claude ได้เลย เช่น "ช่วยติดตั้ง MCP สำหรับ GitHub ให้หน่อย แล้วอธิบายเป็นภาษาไทย" — Claude ติดตั้งให้ได้
ตอนที่ 2

⚡ สร้าง Skill / Slash Command

บันทึก workflow ที่ใช้บ่อยเป็นคำสั่งลัดของคุณเอง

1สร้างคำสั่งลัดของตัวเอง

สร้างไฟล์ .md ในโฟลเดอร์ .claude/commands/ ของโปรเจกต์ ชื่อไฟล์ = ชื่อคำสั่ง

.claude/commands/review.md
# พิมพ์ /review เพื่อรันคำสั่งนี้ ช่วย review โค้ดที่เพิ่งแก้ มองหา bug, ปัญหา security, performance แล้วสรุป เป็นภาษาไทย เรียงตามความสำคัญ

เสร็จแล้วพิมพ์ /review ใน Claude Code ได้เลย

2รับค่าเพิ่มด้วย $ARGUMENTS
.claude/commands/explain.md
อธิบายโค้ดในไฟล์ $ARGUMENTS แบบละเอียดเป็นภาษาไทย # ใช้: /explain src/auth.ts
3หรือให้ Claude สร้างให้

ขี้เกียจเขียนเอง? บอก Claude ได้เลย:

บอก Claude
