Code Review Workflow

ใช้ Claude Code เป็น reviewer ช่วยจับ bug, ปัญหา security, และจุดที่ปรับปรุงได้ ก่อนโค้ดจะขึ้น production

🎯 เมื่อเรียนจบบทนี้ คุณจะ…

  • ใช้ Claude Code ช่วยตรวจสอบโค้ดที่เขียน
  • บอก Claude Code ได้ว่าอยากให้ตรวจเรื่องอะไรบ้าง เช่น หาบั๊ก หรือดูความปลอดภัย
  • ใช้คำสั่งสำเร็จรูป หรือสร้างคำสั่งเอง เพื่อขอให้ Claude Code ช่วยรีวิว

ขอ review ก่อน commit

ให้ Claude ดู diff ปัจจุบันแล้ว review ในมุมต่างๆ: correctness, security, performance, readability

ใช้ slash command ในตัว

Claude Code มี /review สำหรับ review PR และคุณสร้าง custom command เองได้ (ดูบท 7.3)

💬 ลองใช้ Prompt นี้กับ Claude
ช่วย review การเปลี่ยนแปลงที่ฉันเพิ่งทำ (git diff) มองหา: bug ที่อาจเกิด, ช่องโหว่ security, ปัญหา performance, และจุดที่อ่านยาก เรียงตามความสำคัญ
💡
เคล็ดลับ: ให้ review ทีละด้านจะได้ผลลึกกว่า เช่น รอบแรกเน้น security รอบสองเน้น performance
📌 สรุปบทนี้
  • ให้ Claude review diff ก่อน commit
  • ระบุมุมที่อยาก review
  • มี /review ในตัว + custom ได้
🧠 แบบทดสอบท้ายบท
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.การใช้ Claude Code เป็นผู้ช่วยรีวิวโค้ด มีประโยชน์หลักๆ อย่างไร?
เฉลย: Claude Code ทำหน้าที่เป็นผู้ช่วยตรวจโค้ด เพื่อหาข้อผิดพลาดและปรับปรุงคุณภาพก่อนนำไปใช้งาน
ข้อ 2.เราสามารถขอให้ Claude Code ตรวจสอบโค้ดในมุมมองใดได้บ้าง?
เฉลย: Claude Code สามารถช่วยตรวจโค้ดได้หลายด้าน เช่น ความถูกต้องของโค้ด, ช่องโหว่ด้านความปลอดภัย, ประสิทธิภาพการทำงาน และความง่ายในการอ่าน
