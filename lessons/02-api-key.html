บทเรียน 2.2

ตั้งค่า Login และ Billing

Claude Code เข้าสู่ระบบได้ 2 แบบ: ผ่านบัญชี Claude (subscription) หรือผ่าน API key บทนี้อธิบายว่าควรเลือกแบบไหน

🎯 เมื่อเรียนจบบทนี้ คุณจะ…

  • อธิบายวิธีการเข้าสู่ระบบ Claude ได้ 2 แบบ
  • เลือกวิธีเข้าสู่ระบบ Claude ที่เหมาะสมกับงานของตนเองได้
  • ตั้งค่า API Key เพื่อใช้งาน Claude ได้

2 วิธี Login

  • บัญชี Claude (แนะนำ) — login ผ่านเบราว์เซอร์ ใช้โควต้าจาก subscription (Pro/Max) เหมาะกับงานส่วนตัว
  • API Key — จ่ายตามการใช้งานจริง (pay-as-you-go) เหมาะกับทีม, automation, CI/CD

ตั้งค่า API Key

สร้าง key ที่ console.anthropic.com แล้วตั้งเป็น environment variable:

export ANTHROPIC_API_KEY=sk-ant-...
💡
เคล็ดลับ: ใช้งานคนเดียวเริ่มด้วย login บัญชี Claude ง่ายสุด — API key ค่อยใช้ตอนทำ automation/CI
📌 สรุปบทนี้
  • บัญชี Claude เหมาะงานส่วนตัว
  • API key เหมาะ automation/CI
  • API key = จ่ายตามใช้จริง
🧠 แบบทดสอบท้ายบท
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.การเข้าสู่ระบบ Claude มีกี่วิธี?
เฉลย: การเข้าสู่ระบบ Claude ทำได้ 2 วิธี คือผ่านบัญชี Claude หรือ API Key
ข้อ 2.ถ้าคุณใช้งาน Claude คนเดียวและอยากเริ่มแบบง่ายๆ ควรเลือกวิธีไหน?
เฉลย: การเข้าสู่ระบบด้วยบัญชี Claude เหมาะกับงานส่วนตัวและใช้งานง่ายที่สุด
