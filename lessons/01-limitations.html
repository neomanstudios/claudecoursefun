บทเรียน 1.4

ข้อจำกัดที่ต้องรู้ก่อนใช้

รู้ข้อจำกัดก่อนใช้ จะช่วยให้คุณใช้ Claude Code ได้อย่างปลอดภัยและไม่ผิดหวัง บทนี้พูดตรงๆ ว่าอะไรที่ต้องระวัง

🎯 เมื่อเรียนจบบทนี้ คุณจะ…

  • เข้าใจข้อจำกัดพื้นฐานของ Claude Code
  • รู้วิธีรับมือกับข้อจำกัดต่างๆ ของ Claude Code
  • ตรวจสอบงานที่ Claude Code สร้างอย่างรอบคอบก่อนนำไปใช้

ข้อจำกัดที่ต้องรู้

  • Context มีจำกัด — โปรเจกต์ใหญ่มากอาจต้องบอกให้โฟกัสเฉพาะส่วน
  • ไม่รู้ข้อมูลล่าสุดเสมอ — library version ใหม่มากอาจต้องใช้ /context7 ช่วย
  • อาจมั่นใจผิด — ตรวจงานสำคัญเสมอ โดยเฉพาะ logic ธุรกิจและ security
  • ไม่เห็นภาพรวมที่คุณไม่ได้บอก — context ดี = ผลดี

วิธีรับมือ

เขียน CLAUDE.md ให้ดี, ให้ test เป็นตัวตรวจ, review โค้ดก่อน merge, และอย่าให้สิทธิ์รันคำสั่งอันตราย (เช่น rm -rf) แบบอัตโนมัติ

💡
เคล็ดลับ: กฎทอง: Claude Code คือ junior dev ที่เร็วมากและขยันมาก — แต่คุณยังเป็นคน review
📌 สรุปบทนี้
  • Context จำกัด → โฟกัสให้ถูกจุด
  • ตรวจงาน security/logic เสมอ
  • ตั้ง permission ระวังคำสั่งอันตราย
🧠 แบบทดสอบท้ายบท
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.ข้อจำกัดสำคัญของ Claude Code ที่ต้องระวังคืออะไร?
เฉลย: Claude Code อาจไม่รู้ข้อมูลล่าสุด เช่น library version ใหม่ๆ ที่เพิ่งออกมา.
ข้อ 2.ถ้า Claude Code สร้างโค้ดสำคัญมาให้ เราควรทำอย่างไรก่อนนำไปใช้จริง?
เฉลย: เราควรตรวจสอบงานสำคัญที่ Claude Code สร้างมาให้เสมอ โดยเฉพาะเรื่อง logic ธุรกิจและความปลอดภัย เพราะมันอาจมั่นใจผิดได้.
