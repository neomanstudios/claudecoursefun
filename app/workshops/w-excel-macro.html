5 · ระบบอัตโนมัติ & ผู้ช่วย

ทำสูตร/มาโคร Excel ด้วย AI

สร้างสูตรและมาโครจากคำอธิบาย

ความคืบหน้าเวิร์กช็อป
รู้ใน 30 วิ

อธิบายเป็นภาษาคนว่าอยากได้อะไร แล้วให้ AI เขียนสูตรหรือมาโครให้ ไม่ว่าจะเป็นสูตร Excel, Apps Script ของ Google Sheets หรือ VBA งานวนซ้ำในตารางจบในไม่กี่นาที

บอกเป็นคำ ได้สูตรApps Script / VBAวางแล้วรัน ได้เลย

เลือกเครื่องมือให้ตรงงาน

งานในตารางมี 3 ระดับ ใช้ของให้ถูก

1

สูตรในเซลล์

งานคำนวณในแถวเดียว เช่น VLOOKUP หรือ IF ซ้อน บอก AI ว่าอยากได้อะไรแล้ววางสูตรในเซลล์

2

มาโครอัตโนมัติ

งานวนซ้ำหลายขั้น เช่น จัดรูปแบบทั้งชีตหรือส่งเมล ใช้ Apps Script ใน Google Sheets หรือ VBA ใน Excel

3

ทำกับไฟล์จริงหลายไฟล์

รวมหรือล้างข้อมูลหลายไฟล์ในเครื่อง ให้ Claude Code อ่านไฟล์ .xlsx/.csv แล้วเขียนสคริปต์จัดการให้

อย่าถามว่า สูตรนี้เขียนยังไง แต่ อธิบายข้อมูลและผลลัพธ์ที่อยากได้ เช่น คอลัมน์ไหนเป็นอะไร และต้องการเลขแบบไหน AI จะเขียนสูตรที่ใช้ได้จริงให้

ลองเลยจับมือทำ
  1. เปิดแชต AI แล้วอธิบายโครงตารางของคุณ คอลัมน์ไหนเก็บอะไร และผลลัพธ์ที่ต้องการ
  2. ก๊อป prompt นี้แล้วเติมรายละเอียดตารางของคุณ จะได้ทั้งสูตรและคำอธิบาย
    พิมพ์ Prompt นี้
    ฉันมีตาราง Google Sheets: - A: วันที่สั่งซื้อ - B: ชื่อสินค้า - C: ยอดขาย (บาท) ช่วยเขียนสูตรในเซลล์ E2 ที่รวมยอดขายเฉพาะเดือนปัจจุบัน บอกด้วยว่าต้องวางที่เซลล์ไหน และอธิบายแต่ละส่วนของสูตรสั้น ๆ
  3. วางสูตรในเซลล์จริง ถ้าผลไม่ตรง ก๊อปข้อความ error หรือเลขที่ผิดกลับไปบอก AI ให้แก้
  4. ถ้าต้องทำงานวนซ้ำ ขอเป็นมาโคร แล้ววางใน Extensions → Apps Script ของ Google Sheets
    พิมพ์ Prompt นี้
    เขียน Google Apps Script ที่ไล่ทุกแถวในชีต Orders แล้วถ้าคอลัมน์ C (สถานะ) เป็น เสร็จแล้ว ให้ย้ายทั้งแถวไปชีต Done ใส่คอมเมนต์อธิบายแต่ละขั้น และบอกวิธีกดรันด้วย
ลองใช้ Prompt นี้ (อธิบายแล้วได้สูตร)
ฉันใช้ [Excel / Google Sheets] ข้อมูลในตาราง: [อธิบายแต่ละคอลัมน์ เช่น A=ชื่อ, B=คะแนน] สิ่งที่อยากได้: [อธิบายผลลัพธ์ เช่น จัดอันดับคะแนนจากมากไปน้อย] ช่วยเขียนสูตรหรือมาโครให้ บอกด้วยว่าวางที่ไหนและกดรันยังไง อธิบายเป็นภาษาคนสั้น ๆ
สรุปเวิร์กช็อป
  • อธิบายโครงตารางและผลลัพธ์ที่อยากได้ อย่าพยายามนึกชื่อฟังก์ชันเอง
  • สูตรเซลล์ใช้แชตได้ งานวนซ้ำขอเป็น Apps Script หรือ VBA แล้ววางในตาราง
  • ทำกับไฟล์จริงหลายไฟล์ในเครื่อง ให้ Claude Code อ่านและเขียนสคริปต์จัดการให้

ข้อ 1.วิธีขอสูตรจาก AI ให้ได้ผลดีที่สุดคืออะไร?
เฉลย: เมื่อ AI รู้โครงข้อมูลและเป้าหมาย จะเขียนสูตรที่ใช้กับตารางจริงได้ตรง
ข้อ 2.งานวนซ้ำหลายขั้นในตาราง เช่น ย้ายแถวอัตโนมัติ ควรขอเป็นอะไร?
เฉลย: งานวนซ้ำหลายขั้นทำด้วยสูตรเซลล์ไม่ได้ ต้องใช้สคริปต์มาโครจัดการ
