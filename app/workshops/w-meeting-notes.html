ถอดเสียง & สรุปประชุม

ได้บันทึกและสรุปการประชุมอัตโนมัติ

ความคืบหน้าเวิร์กช็อป
รู้ใน 30 วิ

ปล่อยให้ AI ถอดเสียงและสรุปการประชุม ให้อัตโนมัติ ใช้ Otter หรือ tl;dv จับเสียงสด หรืออัปโหลดไฟล์อัด แล้วได้บันทึกพร้อม action items ที่ใครต้องทำอะไร

ถอดเสียง อัตโนมัติสรุป เป็นประเด็นAction items ใครทำอะไร

อัปโหลดไฟล์ + AI
มีไฟล์อัดอยู่แล้ว โยนเข้า AI ให้ถอดและสรุป
มีไฟล์แล้ว

transcript ดิบยาวเป็นพืด ไม่มีใครอ่าน คุณค่าจริงอยู่ที่ สรุปเป็นประเด็น และ action items ว่าใครต้องทำอะไรภายในเมื่อไหร่

ลองเลยจับมือทำ
  1. ติดตั้ง tl;dv แล้วเชื่อมกับ Google Calendar ให้มันเข้าร่วมประชุมออนไลน์อัตโนมัติ (หรืออัด/อัปโหลดไฟล์เสียงก็ได้)
  2. หลังประชุมจบ เปิดดู transcript ที่ระบบถอดให้ ตรวจชื่อผู้พูดและศัพท์เฉพาะว่าถูกไหม
  3. ก๊อป transcript ไปวางในแชต AI แล้วใช้ prompt นี้เพื่อให้ได้สรุปและ action items
    พิมพ์ Prompt นี้
    นี่คือ transcript การประชุม ช่วยสรุปให้: 1. ประเด็นหลักที่คุยกัน เป็นข้อ ๆ 2. การตัดสินใจที่สรุปได้แล้ว 3. Action items ในรูปแบบ: [ชื่อคน] - [สิ่งที่ต้องทำ] - [กำหนดส่ง ถ้ามี] ถ้าตรงไหนไม่ชัดในบทสนทนา อย่าเดา ให้ระบุว่าต้องยืนยันเพิ่ม Transcript: [วาง transcript ที่นี่]
  4. ส่งสรุปให้ทีมในแชตหรืออีเมล แล้วแปะ action items เข้า task ที่ทีมใช้
  5. ถ้าไฟล์ transcript อยู่ในเครื่อง ให้ Claude Code อ่านไฟล์ สรุป และเซฟเป็น notes.md ให้เลย
ลองใช้ Prompt นี้ (สรุป + action items)
สรุปการประชุมจาก transcript นี้สำหรับคนที่ไม่ได้เข้าร่วม รูปแบบ: - สรุป 3-5 ประเด็นหลัก - การตัดสินใจที่ได้ข้อสรุป - Action items: [ผู้รับผิดชอบ] - [งาน] - [กำหนด] - ประเด็นค้าง ที่ยังไม่สรุป อย่าเดาข้อมูลที่ไม่มีใน transcript Transcript: [วาง transcript]
สรุปเวิร์กช็อป
  • ใช้ tl;dv หรือ Otter จับเสียงสด หรืออัปโหลดไฟล์อัดเข้า AI ให้ถอดเสียง
  • คุณค่าจริงคือสรุปเป็นประเด็นและ action items ไม่ใช่ transcript ดิบ
  • ไฟล์ transcript ในเครื่อง ให้ Claude Code อ่าน สรุป และเซฟเป็นไฟล์ให้เลย
ในเวิร์กช็อปนี้
เลือกเครื่องมือถอดเสียงลองเลยแบบทดสอบ
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.ผลลัพธ์ที่มีค่าที่สุดจากการสรุปประชุมด้วย AI คืออะไร?
เฉลย: transcript ดิบยาวเกินอ่าน คนต้องการสรุปประเด็นและสิ่งที่ต้องลงมือทำต่อ
ข้อ 2.ควรสั่ง AI อย่างไรเมื่อบางประเด็นใน transcript ยังไม่ชัด?
เฉลย: การสั่งไม่ให้เดาช่วยกันสรุปที่ผิดพลาด และชี้จุดที่ต้องตามต่อจริง
