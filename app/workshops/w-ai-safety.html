1 · เริ่มต้นกับ AI

ความปลอดภัยเมื่อใช้ AI

ใช้ AI อย่างปลอดภัย ไม่หลุดข้อมูลส่วนตัว

ความคืบหน้าเวิร์กช็อป
รู้ใน 30 วิ

ทุกอย่างที่พิมพ์ลงแชต AI อาจถูกเก็บไว้ ห้ามวางรหัสผ่าน API key หรือเลขบัตรประชาชนเด็ดขาด ใช้ [ค่าสมมติ] แทนข้อมูลจริงเสมอ

ห้ามวาง รหัสผ่าน/คีย์/บัตรปชช.ผู้ให้บริการ อาจเก็บข้อมูลใช้ค่าสมมติ แทนข้อมูลจริง

ข้อมูลอะไรห้ามวางลงแชต

กฎง่าย ๆ คือ ถ้าหลุดแล้วเดือดร้อน อย่าพิมพ์ลงไป

1

รหัสผ่านและคีย์

ห้ามวาง รหัสผ่าน, API key, token หรือ secret ใด ๆ ถ้าหลุดออกไป คนอื่นเข้าระบบหรือใช้เงินในบัญชีคุณได้

2

ข้อมูลส่วนตัว (PII)

เลขบัตรประชาชน เลขบัตรเครดิต เบอร์โทร ที่อยู่ ข้อมูลสุขภาพ ของตัวเองและของคนอื่น ล้วนเป็นข้อมูลอ่อนไหวที่ไม่ควรพิมพ์

3

ข้อมูลบริษัท

โค้ดลับ สัญญา ข้อมูลลูกค้า หรือตัวเลขที่ยังไม่เปิดเผย หลายบริษัทมี นโยบายห้ามวางลง AI สาธารณะ เช็กกับที่ทำงานก่อน

ถือว่าทุกอย่างที่พิมพ์ลงแชต AI อาจถูกเก็บและนำไปใช้เทรนโมเดล ได้ ก่อนกด Enter ถามตัวเองว่าข้อมูลนี้หลุดออกไปแล้วโอเคไหม

ผู้ให้บริการเก็บอะไรบ้าง

รู้ไว้เพื่อตั้งค่าและใช้งานอย่างปลอดภัย

1

บทสนทนาถูกเก็บไว้

ChatGPT, Claude, Gemini เก็บประวัติแชตไว้ในบัญชีคุณ และทีมงานอาจเข้าถึงได้บางกรณีเพื่อตรวจสอบความปลอดภัย

2

อาจถูกใช้เทรนโมเดล

บัญชีฟรีบางแบบนำแชตไปปรับปรุงโมเดลต่อ มักปิดได้ใน Settings เช่น ปิด Improve the model for everyone ใน ChatGPT

3

แพลนธุรกิจปลอดภัยกว่า

แพลน Team หรือ Enterprise มักไม่นำข้อมูลไปเทรน ถ้าใช้กับงานบริษัทควรเลือกแพลนที่มีข้อตกลงเรื่องข้อมูลชัดเจน

ลองเลยจับมือทำ
  1. เปิด Settings ของ ChatGPT หรือ Claude แล้วหาหัวข้อ Data controls ปิดการนำแชตไปเทรนโมเดลถ้าไม่ต้องการ
  2. หยิบงานจริงที่มีข้อมูลอ่อนไหว เช่น อีเมลลูกค้า หรือสัญญา ที่อยากให้ AI ช่วย
  3. แทนข้อมูลจริงด้วยค่าสมมติก่อนวาง แล้วใช้ Prompt แบบนี้ พอได้ผลค่อยเอาข้อมูลจริงไปเติมเองในเครื่อง
    พิมพ์ Prompt นี้
    ช่วยร่างอีเมลแจ้งลูกค้าเรื่องเลื่อนนัดส่งของให้หน่อย ใช้ข้อมูลสมมติแทนข้อมูลจริงดังนี้: ชื่อลูกค้า: [คุณสมชาย] เลขออเดอร์: [ORDER-0001] วันส่งใหม่: [15 ก.ค.] โทนสุภาพ ขอโทษสั้น ๆ และเสนอส่วนลดเล็กน้อยเป็นการชดเชย
  4. ตรวจก่อนกด Enter ทุกครั้งว่าไม่มีรหัสผ่าน คีย์ หรือเลขบัตรหลุดไปในข้อความ
วิธีถามโดยไม่หลุดข้อมูลจริง
ช่วย [งานที่ต้องการ เช่น ร่างสัญญา/วิเคราะห์ข้อมูล] ให้หน่อย โดยฉันจะใช้ค่าสมมติแทนข้อมูลจริงทั้งหมด เช่น ชื่อ [คุณสมชาย] บริษัท [ABC จำกัด] ตัวเลข [1000] เมื่อได้ผลลัพธ์แล้วฉันจะนำไปแทนข้อมูลจริงเองในเครื่อง
สรุปเวิร์กช็อป
  • ห้ามวางรหัสผ่าน API key เลขบัตรประชาชน หรือข้อมูลส่วนตัวลงแชต AI เด็ดขาด
  • ถือว่าทุกข้อความอาจถูกเก็บและนำไปเทรนโมเดล เช็กนโยบายข้อมูลของบริษัทก่อนใช้กับงาน
  • ใช้ค่าสมมติหรือ placeholder แทนข้อมูลจริง แล้วค่อยเติมข้อมูลจริงเองในเครื่อง
ในเวิร์กช็อปนี้
ข้อมูลอะไรห้ามวางลงแชตผู้ให้บริการเก็บอะไรบ้างลองเลยแบบทดสอบ
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.ข้อใดไม่ควรพิมพ์ลงแชต AI สาธารณะ?
เฉลย: API key และรหัสผ่านเป็นความลับ ถ้าหลุดออกไปคนอื่นอาจเข้าถึงระบบหรือบัญชีของคุณได้
ข้อ 2.เพื่อความปลอดภัย ควรจัดการกับข้อมูลส่วนตัวในงานอย่างไรก่อนวางลงแชต?
เฉลย: การใช้ค่าสมมติแทนข้อมูลจริงทำให้ได้ผลลัพธ์ที่ต้องการโดยไม่เสี่ยงข้อมูลหลุด
ข้อ 3.ข้อใดถูกต้องเกี่ยวกับการเก็บข้อมูลของผู้ให้บริการ AI?
เฉลย: ผู้ให้บริการมักเก็บประวัติแชต และบางแพลนนำไปใช้ปรับปรุงโมเดล ซึ่งมักปิดได้ในการตั้งค่า
