7 · การศึกษา & เรียนรู้

ทำ flashcard/quiz จากเนื้อหา

สร้างการ์ดคำถามไว้ทบทวน

ความคืบหน้าเวิร์กช็อป
รู้ใน 30 วิ

เปลี่ยนโน้ตที่จดไว้ให้เป็น การ์ดคำถาม-คำตอบ พร้อมใช้ใน Anki แล้วทบทวนแบบ spaced repetition ให้สมองจำได้ยาวก่อนสอบ

โน้ต เป็นการ์ด Q&AAnki import ได้เลยทบทวน แบบเว้นระยะ

การ์ดที่ดีเป็นแบบไหน

การ์ดดีช่วยให้จำ การ์ดแย่แค่ทำให้เหนื่อย

1

1 การ์ด 1 ความคิด

อย่ายัดทั้งย่อหน้าลงการ์ดเดียว แตกเป็นหลายใบที่ถามทีละจุด สมองจะจำง่ายกว่า

2

ถามแบบให้ดึงความจำ

ตั้งคำถามที่ต้องนึกคำตอบเอง ไม่ใช่เลือกถูก/ผิด การ active recall ทำให้จำได้แน่นกว่า

3

spaced repetition

Anki จะเอาการ์ดที่เราตอบยากกลับมาถามถี่ขึ้น การ์ดที่จำได้แล้วก็ทิ้งช่วงนานขึ้น

ขอ AI ส่งการ์ดเป็นไฟล์ CSV หรือคั่นด้วย Tab โดยให้ คำถามอยู่คอลัมน์แรก คำตอบอยู่คอลัมน์สอง แล้วเอาเข้า Anki ได้ในคลิกเดียว

ลองเลยจับมือทำ
  1. ก๊อปโน้ตหรือสรุปบทเรียนที่อยากทบทวน เตรียมวางในแชต AI
  2. วางโน้ตต่อท้าย Prompt นี้ แล้วส่ง
    พิมพ์ Prompt นี้
    ช่วยเปลี่ยนโน้ตด้านล่างเป็น flashcard แบบถาม-ตอบ สำหรับ import เข้า Anki กติกา: 1. 1 การ์ด ถามแค่ 1 ความคิด อย่ายัดหลายเรื่องในใบเดียว 2. ตั้งคำถามแบบให้นึกคำตอบเอง (active recall) ห้ามถามแบบใช่/ไม่ใช่ 3. ส่งผลเป็นตารางคั่นด้วยเครื่องหมาย ; โดยคอลัมน์แรกเป็นคำถาม คอลัมน์สองเป็นคำตอบสั้น ๆ โน้ต: [วางโน้ตของคุณตรงนี้]
  3. ก๊อปตารางที่ได้ไปวางในไฟล์ .txt แล้วเซฟ
  4. เปิด Anki กด File > Import เลือกไฟล์ ตั้ง Fields separated by เป็น Semicolon แล้วกด Import
  5. เริ่มทบทวน Anki จะจัดตารางทวนซ้ำแบบ spaced repetition ให้เอง
ลองใช้ Prompt นี้
ช่วยทำ flashcard 10 ใบจากหัวข้อ [ชื่อหัวข้อ] ระดับ [ม.ปลาย/มหาลัย] ตั้งคำถามแบบ active recall 1 การ์ด 1 ความคิด ส่งเป็นตารางคั่นด้วย ; คอลัมน์แรกคำถาม คอลัมน์สองคำตอบ
สรุปเวิร์กช็อป
  • ทำการ์ด 1 ใบต่อ 1 ความคิด และถามแบบให้นึกคำตอบเอง (active recall)
  • ขอ AI ส่งผลเป็น CSV หรือคั่นด้วย ; เพื่อ import เข้า Anki ได้ทันที
  • ทบทวนด้วย spaced repetition แทนการอ่านรวดเดียวก่อนสอบ
ในเวิร์กช็อปนี้
การ์ดที่ดีเป็นแบบไหนลองเลยแบบทดสอบ
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.flashcard ที่ดีควรเป็นยังไง?
เฉลย: การ์ดที่ถาม 1 ความคิดและใช้ active recall ช่วยให้สมองจำได้แน่นกว่า
ข้อ 2.spaced repetition ใน Anki ช่วยเรื่องอะไร?
เฉลย: Anki เว้นระยะการทวนตามความยาก ทำให้จำได้ยาวโดยไม่เสียเวลาทวนของที่จำได้แล้ว
