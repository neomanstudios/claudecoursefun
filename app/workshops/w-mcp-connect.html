เชื่อม AI กับเครื่องมือ (MCP)

ต่อ AI เข้ากับเครื่องมือที่ใช้อยู่

ความคืบหน้าเวิร์กช็อป
รู้ใน 30 วิ

MCP คือมาตรฐานที่ให้ AI ต่อเข้ากับเครื่องมือที่คุณใช้จริง เช่น GitHub, ฐานข้อมูล หรือ Notion เพิ่ม MCP server เข้า Claude Code ครั้งเดียว แล้วมันก็เรียกใช้เครื่องมือนั้นได้เอง

MCP = ปลั๊กต่อเครื่องมือServer = ตัวต่อ 1 ตัว/เครื่องมือclaude mcp add

MCP คืออะไร

คิดง่าย ๆ ว่าเป็นช่องเสียบมาตรฐานให้ AI ต่อเครื่องมือ

1

ปัญหาเดิม

AI รู้แค่สิ่งที่เทรนมา ต่อกับ GitHub, ฐานข้อมูล หรือ Notion ของคุณเองไม่ได้

2

MCP server

ตัวกลางหนึ่งตัวต่อหนึ่งเครื่องมือ คอยเปิดความสามารถของเครื่องมือนั้นให้ AI เรียกใช้

3

ต่อครั้งเดียว ใช้ยาว

เพิ่ม server เข้า Claude Code แล้ว มันจะเห็นและเรียกเครื่องมือนั้นได้เองในทุกงานต่อไป

MCP ทำให้ Claude Code ไม่ได้รู้แค่โค้ดในเครื่อง แต่ เอื้อมไปแตะเครื่องมือจริง ได้ เช่น เปิด issue ใน GitHub หรือ query ฐานข้อมูล โดยไม่ต้องสลับแอป

ลองเลยจับมือทำ
  1. เปิดเทอร์มินัล แล้วดูว่ามี server อะไรต่ออยู่บ้างด้วย claude mcp list
  2. เพิ่ม MCP server ของ GitHub เข้ามา (รันในเทอร์มินัล ไม่ใช่ในแชต)
    คัดลอกคำสั่งนี้
    claude mcp add github -- npx -y @modelcontextprotocol/server-github
  3. เข้า Claude Code ด้วย claude แล้วพิมพ์ /mcp เพื่อเช็กว่า server ต่อติดและเห็นเครื่องมือแล้ว
  4. สั่งงานที่ต้องใช้เครื่องมือนั้นจริง Claude Code จะเรียก MCP เอง
    พิมพ์ Prompt นี้
    ดู issue ที่เปิดอยู่ใน repo [owner/repo] แล้วสรุปว่าแต่ละอันเกี่ยวกับอะไร เรียงตามความเร่งด่วน
  5. ถ้าต้องใช้ token ครั้งแรก Claude Code จะบอกให้ตั้งค่า ทำตามที่มันแนะนำได้เลย
ลองใช้ Prompt นี้ (หลังต่อ MCP แล้ว)
ใช้เครื่องมือ [ชื่อ MCP เช่น GitHub / ฐานข้อมูล] ที่ต่อไว้ ช่วย [งานที่ต้องการ เช่น ดึงรายการลูกค้าที่สมัครเดือนนี้ / สรุป issue ที่ยังไม่ปิด] ถ้าต้องสิทธิ์เพิ่มหรือข้อมูลอะไร ให้ถามก่อนลงมือ
สรุปเวิร์กช็อป
  • MCP คือมาตรฐานที่ให้ AI ต่อเข้ากับเครื่องมือจริงของคุณ หนึ่ง server ต่อหนึ่งเครื่องมือ
  • เพิ่ม server ด้วย claude mcp add ครั้งเดียว แล้ว Claude Code เรียกใช้ได้เองตลอด
  • ตรวจการเชื่อมต่อด้วย /mcp ก่อนสั่งงานที่ต้องใช้เครื่องมือนั้น
ในเวิร์กช็อปนี้
MCP คืออะไรลองเลยแบบทดสอบ
แบบทดสอบท้ายเวิร์กช็อป
ลองตอบดู แล้วระบบจะเฉลยให้ทันที
ข้อ 1.MCP server ทำหน้าที่อะไร?
เฉลย: MCP server หนึ่งตัวเชื่อม AI เข้ากับเครื่องมือหนึ่งอย่างให้เรียกใช้ได้
ข้อ 2.หลังรัน claude mcp add แล้ว ควรทำอะไรก่อนสั่งงานจริง?
เฉลย: คำสั่ง /mcp ยืนยันว่า server เชื่อมต่อสำเร็จก่อนจะใช้งานเครื่องมือนั้น
