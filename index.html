Quick Reference

Commands ที่ใช้บ่อย

copy ไปใช้ได้เลย ไม่ต้องจำ

⚡ Basic Commands
# เริ่ม session ใหม่ claude # บอกงานตรงๆ claude "สร้าง REST API สำหรับ user auth" # ใช้ในโฟลเดอร์ project claude --add-dir ./src "review code ทั้งหมด" # Headless mode (CI/CD) claude -p "รัน tests และ fix ถ้าพัง" --output-format json
💬 Slash Commands
/help — ดู commands ทั้งหมด /compact — ย่อ context ให้สั้นลง /clear — เริ่ม session ใหม่สะอาด /resume — กลับ session ที่ค้างอยู่ /review — custom: code review /deploy — custom: deploy workflow /test — custom: run + fix tests
📋 CLAUDE.md Template
# Project Name ## Tech Stack - Node.js v22, TypeScript strict - PostgreSQL + Drizzle ORM - React 19 + TailwindCSS v4 ## Conventions - ใช้ camelCase สำหรับ variables - ทุก function ต้องมี return type - error handling ด้วย Result type ## NEVER - อย่าใช้ any ใน TypeScript - อย่า commit โดยไม่รัน tests - อย่าลบ .env.example
🪝 Hooks Example
// settings.json { "hooks": { "PostToolUse": [{ "matcher": "Write", "hooks": [{ "type": "command", "command": "npm test" }] }], "Stop": [{ "command": "./notify.sh" }] } }
