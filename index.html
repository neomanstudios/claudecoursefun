🎯 Custom Slash Commands ทำงานยังไง? ▼
สร้างไฟล์ใน .claude/commands/ เช่น deploy.md แล้วใส่ prompt ที่ต้องการ เมื่อพิมพ์ /deploy Claude จะรันตาม instruction ที่กำหนดไว้ทันที สามารถรับ argument ได้ด้วย $ARGUMENTS
🔌 MCP Server คือ? ▼
Model Context Protocol — มาตรฐานการเชื่อม tool ภายนอกเข้ากับ Claude เช่น เชื่อม PostgreSQL, Slack, GitHub, Figma เข้าไปใน context Claude จะสามารถ query database, post Slack message, create PR ได้โดยตรง
🪝 Hooks คืออะไร ใช้งานยังไง? ▼
Hook คือ shell script ที่รันอัตโนมัติเมื่อ Claude ทำบางอย่าง เช่น PreToolUse: ก่อน Claude รันคำสั่ง — ใช้ validate หรือ log PostToolUse: หลังรัน — ใช้ trigger test หรือ notification Stop: เมื่อ Claude เสร็จงาน — ใช้ deploy หรือ send report

Pro Tips ที่ ต้องรู้

เทคนิคจากการใช้งานจริง ที่จะทำให้คุณทำงานได้เร็วและดีขึ้น

📌
เขียน CLAUDE.md ให้ดีตั้งแต่แรก
ไฟล์ CLAUDE.md คือ "คู่มือ project" ที่ Claude อ่านทุกครั้ง ใส่ข้อมูลสำคัญเช่น tech stack, coding conventions, architecture decisions, และสิ่งที่ Claude ห้ามทำ โดยเด็ดขาด
# CLAUDE.md
## Tech Stack
- Node.js v22, TypeScript strict mode
- PostgreSQL + Drizzle ORM
## NEVER
- อย่าใช้ any ใน TypeScript
- อย่า commit โดยไม่รัน tests
🎯
ให้ Claude คิดก่อน แล้วค่อยทำ
เพิ่ม "ก่อนเขียนโค้ด ช่วยอธิบาย approach ที่จะใช้ก่อน" ในทุก prompt ที่ซับซ้อน จะทำให้ Claude วางแผนดีขึ้น และคุณสามารถ redirect ก่อนที่จะสายเกินไป
# ❌ แบบไม่ดี
สร้าง payment system
# ✅ แบบดี
ก่อนเขียนโค้ด อธิบาย architecture
และ trade-offs ของ payment system ก่อน
🔄
ใช้ /compact และ /clear อย่างถูกเวลา
Context window มีจำกัด เมื่อทำงานนานๆ ใช้ /compact เพื่อ summarize conversation และลดขนาด context ส่วน /clear ใช้เมื่อเริ่ม task ใหม่ ที่ไม่เกี่ยวกับ task เดิมเลย
/compact ← ย่อ context ไว้
/clear ← เริ่มใหม่สะอาด
/resume ← กลับมา session เดิม
🛡️
ตั้งค่า Permissions อย่างระมัดระวัง
Claude Code มีระบบ permission ที่ต้องตั้งค่าก่อน allow อะไร ใช้ allowedTools ใน settings.json เพื่อกำหนดว่า Claude ทำอะไรได้บ้างโดยไม่ต้องขออนุมัติ ลด friction ใน development workflow
// settings.json
"allowedTools": [
 "Bash(npm:*)",
 "Bash(git:*)",
 "Bash(rm:*)" ← อย่า allow!
]
