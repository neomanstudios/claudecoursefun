3 เรื่องที่ทำให้คุณ สบายใจ

มือใหม่ทุกคนกลัวเหมือนกัน — แต่ความจริงคือ...

🗣️
คุณแค่ "พูด" ไม่ต้อง "เขียนโค้ด"
พิมพ์บอกเป็นภาษาไทยธรรมดา เหมือนสั่งงานเพื่อน แล้ว Claude เขียนโค้ดให้
💻
ทุกอย่างอยู่บนเครื่องคุณ
ไฟล์เว็บอยู่ในเครื่องคุณเอง เปิดดู แก้ไข เก็บไว้ได้ตลอด เป็นเจ้าของจริงๆ
🛡️
คุณทำพังไม่ได้
Claude ถามก่อนทำทุกครั้งที่สำคัญ ลองได้เต็มที่ ผิดก็บอกให้แก้ใหม่ได้

🤔 "รันบนเครื่อง" (Local Run) คืออะไร?

คือการที่เว็บของคุณ ทำงานอยู่บนคอมพิวเตอร์ของคุณเอง ไม่ใช่บนเว็บคนอื่น — เหมือนทำอาหารกินเองที่บ้าน คุณคุมทุกอย่าง เห็นทุกไฟล์ แก้ได้ทันที ไม่ต้องต่อเน็ตก็เปิดดูได้

💻 Local Run (ที่เราจะทำ)
  • เว็บรันบนเครื่องคุณ
  • เป็นเจ้าของไฟล์ทั้งหมด
  • แก้ไขได้อิสระ ไม่จำกัด
  • เห็นผลทันทีขณะแก้
🌐 Deploy (ขั้นต่อไป)
  • เอาเว็บขึ้นออนไลน์
  • คนอื่นเปิดดูได้ด้วยลิงก์
  • ทำเมื่อพอใจแล้ว
  • มีบทเรียนแยกข้างล่าง

🤔 Claude ตอบเป็นภาษาอังกฤษ▼
พิมพ์บอกไปว่า "ตอบเป็นภาษาไทยนะ" แล้ว Claude จะเปลี่ยนมาเป็นไทยทันที
😅 ไม่รู้ว่าไฟล์เว็บอยู่ตรงไหนในเครื่อง▼
พิมพ์ถาม Claude ได้เลย: "ไฟล์เว็บอยู่ที่ไหนในเครื่อง บอกที่อยู่หน่อย" Claude จะบอก path เต็มให้ หรือบอกว่า "เปิดโฟลเดอร์ที่เก็บไฟล์ให้หน่อย"
💸 ต้องเสียเงินไหม?▼
Node.js และการรันบนเครื่อง ฟรีทั้งหมด ส่วน Claude มีแพลนฟรีให้ลองใช้ ถ้าใช้หนักค่อยอัปเกรด — การ deploy ที่แนะนำก็มีแพลนฟรีทุกเจ้า
🆘 งงตรงไหน ถาม Claude ได้ไหม?▼
ได้เลย! Claude คุยด้วยได้ ถามอะไรก็ได้ เช่น "อธิบายให้ฟังหน่อยว่าตอนนี้ต้องทำอะไรต่อ" หรือ "คำสั่งเมื่อกี้ทำอะไร" ถามเหมือนถามเพื่อนที่รู้เรื่องคอมได้
